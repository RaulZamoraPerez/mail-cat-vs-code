# Changelog

All notable changes to MailCat will be documented in this file.

## [1.0.0] - 2026-05-10

### Initial Release

#### Features
- **Local SMTP Server**: Run a private SMTP server on localhost:2525
- **Email Preview**: View emails with accurate HTML rendering
- **Responsive Devices**: Test preview on Desktop, Tablet, and Mobile
- **Dark Mode**: Toggle between light and dark themes
- **Fullscreen View**: Open emails in fullscreen with device mockups
- **Spam Analysis**: Analyze emails for spam score and issues
- **HTML Validation**: Check CSS compatibility with email clients
- **ESLint Validation**: Detect email template problems
- **HTML Check**: Verify HTML structure and best practices
- **Configuration Management**: Easy SMTP settings storage
- **Code Snippets**: Quick integration examples for 5+ languages

#### Integrations
- **Node.js**: Nodemailer examples
- **Python**: smtplib examples
- **PHP**: Laravel Mail examples
- **Java**: Jakarta Mail examples

#### Supported Email Clients
- Gmail
- Outlook
- Apple Mail
- Samsung Mail
- And more via compatibility analysis

#### User Interface
- Sidebar panel with email inbox
- Tab-based email viewer
- Real-time email capture
- Search functionality
- Email storage (up to 50 emails in memory)
- SMTP configuration panel

### Technical
- TypeScript implementation
- VS Code API integration
- Mailparser integration for email parsing
- SMTP Server library
- Responsive design with CSS Grid

### Documentation
- Professional README with screenshots
- MIT License included
- GitHub repository links
- Bug report integration
